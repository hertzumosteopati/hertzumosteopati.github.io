# Logos

All files are outlined SVG (no font dependency) and use the exact token values: tang #1F3A33, kalk #EEF0EA, rav #E0A146. The mark is a monogram H with an arch for a crossbar and the amber touchpoint on its apex; the wordmark is "Hertzum" (600) and "Osteopati" (450) in Bricolage Grotesque, outlined.

| File | Use |
| --- | --- |
| `lockup-horizontal.svg` | Default. Site header, documents, email signatures. On `kalk`, `bone`, `siv` or `sand`. Minimum height 32px. |
| `lockup-horizontal-reversed.svg` | On `tang` panels: the footer, the reversed about-page hero. Kalk strokes and text, rav touchpoint. |
| `lockup-horizontal-mono.svg` | Single-ink tang for print, stamps and over photography on a solid kalk tile. The touchpoint is tang too. |
| `wordmark.svg` | The two words without the mark, for places the mark already appears (next to a favicon-size tile, in a document footer). |
| `wordmark-stacked.svg` | Mark above "Hertzum" over "Osteopati". Social covers and the about-page hero only. Minimum width 200px. |
| `mark.svg` | The mark alone, tang strokes and rav dot on a transparent ground, for small inline uses on kalk. Minimum 24px. |
| `mark-on-tang.svg` | Favicon, app icon and social avatar: tang tile at `radius-m`, kalk strokes, rav dot. |
| `mark-reversed.svg` | The mark alone on a tang panel. |
| `mark-mono.svg` | Single-ink tang, dot included, for one-colour contexts. |

Clear space is one stem-width (8 units of the 64-unit box, i.e. an eighth of the mark's height) on all sides. Do not recolour the stems, move or drop the dot, rotate, outline, add shadows, or re-set the wordmark in another face.
